{# ── Twilio ── #}
{% trans "How to configure Twilio" %}
{# Before you start #}

{% trans "Before you start" %}

  • {% trans "You need a Twilio account. Sign twilio.com/try-twilio up free at" %} console.twilio.com/dashboard?variant_override=non-dev {% trans "(a trial account is enough for testing)." %}
{# Part 1 #}

{% trans "Part 1 — Collect your details from Twilio" %}

  1. {% trans "Sign in to the Twilio Console" %} — {% trans "Sign in, then open the classic Console layout, which this guide uses:" %} console.twilio.com/dashboard?variant_override=non-dev. {% trans "You land on the Account Dashboard, with Develop and Monitor tabs in the sidebar. If Twilio shows a different layout, look for the same items under the Communications menu." %}
  2. {% trans "Copy the Account SID" %} — {% trans "On the dashboard, scroll to the Account Info box. Copy the Account SID (a 34-character value starting with AC)." %}
  3. {% trans "Copy the Auth Token" %} — {% trans "In the same Account Info box, click Show next to Auth Token and copy it. Treat it like a password." %}
  4. {% trans "Get a Twilio phone number" %} — {% trans "On the Account Dashboard, under Connect to 3rd-party applications, the item Twilio phone number must be ticked. If it is not, click Get a trial phone number and accept the number Twilio suggests (a paid account can buy one under Phone Numbers → Manage → Buy a number)." %}
  5. {% trans "Copy that number" %} — {% trans "Go to Phone Numbers → Manage → Active numbers and copy the number in E.164 format: a plus sign, the country code, then the digits with no spaces or dashes (e.g. +12125551234). This is your Default Caller ID." %}
  6. {% trans "Allow calls to your country" %} — {% trans "Go to Voice → Settings → Geo permissions and enable the country you will be calling (for example India or United Kingdom). Calls to a disabled country fail with error 21215." %}
{# Part 2 #}

{% trans "Part 2 — Trial accounts only: verify the phone you will call" %}

{% trans "A Twilio trial account can only call numbers you have verified. Skip this part if you have upgraded to a paid account." %}

  1. {% trans "In the Twilio Console open Phone Numbers → Manage → Verified Caller IDs. The phone number you signed up with is normally already verified." %}
  2. {% trans "Click Add a new Caller ID, choose your country, enter the mobile number you want to test with, and choose Call or SMS." %}
  3. {% trans "Enter the verification code Twilio sends or reads out. The number now shows in the Verified Caller IDs list." %}
  4. {% trans "Use this verified number as the phone number on the Lead or Contact you test with. Calling any other number fails with error 21608." %}
{# Part 3 #}

{% trans "Part 3 — Enter the details in this form" %}

{% trans "Click Add above and fill in the form:" %}

  • {% trans "Name" %} — {% trans "Any label, for example Twilio Main." %}
  • {% trans "Provider" %} — {% trans "Select Twilio." %}
  • {% trans "Status" %} — {% trans "Set to Active. The default is Inactive, and an Inactive provider is not offered when users click Call Now." %}
  • {% trans "Default Caller ID" %} — {% trans "Paste the Twilio phone number from Part 1. It must be a number you own in Twilio — a personal mobile number is rejected (error 21210 or 21212)." %}
  • {% trans "Account SID" %} — {% trans "Paste the value starting with AC." %}
  • {% trans "Auth Token / API Secret" %} — {% trans "Paste the Auth Token." %}
  • {% trans "Webhook verification" %} — {% trans "Nothing extra to enter. Twilio signs its status callbacks with your Auth Token, and the CRM rejects any callback that is not signed with it. Trial accounts have an Auth Token too." %}

{% trans "Click Save, then use the Test Connection action on the provider row. You should see Connection successful. If you see HTTP 401, the Account SID or Auth Token is wrong or has extra spaces." %}

{# ── SignalWire ── #}
{% trans "How to configure SignalWire (Beta)" %}
{# Before you start #}

{% trans "Before you start" %}

  • {% trans "You need a SignalWire account. Sign up free at" %} signalwire.com {% trans "(a trial account is enough for testing)." %}
{# Part 1 #}

{% trans "Part 1 — Collect your details from SignalWire" %}

  1. {% trans "Sign in to SignalWire" %} — {% trans "Go to" %} signalwire.com, {% trans "click Log in, and open your Space. You land on the Dashboard at https://your-space.signalwire.com/dashboard." %}
  2. {% trans "Copy the Project ID" %} — {% trans "On the Dashboard, find the line Project ID near the top and copy it (a long value like 797923a2-413f-416c-830f-bbf5b5c215d3). This is the Account SID in the CRM form." %}
  3. {% trans "Copy the Space URL" %} — {% trans "On the same Dashboard, find the line URL (for example your-space.signalwire.com) and copy it. This is the API Base URL in the CRM form." %}
  4. {% trans "Create an API token" %} — {% trans "In the left sidebar click API Credentials. Under Tokens click New, give it a name such as CRM, tick the permission for the Compatibility API (or Voice) if asked, and save. Copy the token straight away — it is shown only once. This is the Auth Token in the CRM form. Your login password and the Project ID are not tokens." %}
  5. {% trans "Find your phone number" %} — {% trans "In the left sidebar click Phone Numbers. Your numbers are listed under Purchased Numbers; a trial account normally includes one. If the list is empty, click Buy and choose a number with Voice enabled." %}
  6. {% trans "Copy that number" %} — {% trans "Copy it in E.164 format: a plus sign, the country code, then the digits with no spaces, brackets or dashes. For example +1 (202) 900-4429 becomes +12029004429. This is your Default Caller ID." %}
{# Part 2 #}

{% trans "Part 2 — Trial accounts only: verify the phone you will call" %}

{% trans "A SignalWire trial account can only call numbers you have verified. Skip this part if you have exited trial mode." %}

  1. {% trans "In the left sidebar open Phone Numbers → Verified and add a new number." %}
  2. {% trans "Enter the mobile number you want to test with, including the country code (e.g. +14155550123), then click Call Me." %}
  3. {% trans "Answer the call and enter the verification code it reads out. The number now shows in the Verified list." %}
  4. {% trans "If you see Number must be from an allowed region, trial accounts only accept numbers from certain countries. Use a number from an allowed country, or click Exit Trial Mode (add a credit card and top up your balance) to remove the restriction." %}
  5. {% trans "Use this verified number as the phone number on the Lead or Contact you test with." %}
{# Part 3 #}

{% trans "Part 3 — Enter the details in this form" %}

{% trans "Click Add above and fill in the form:" %}

  • {% trans "Name" %} — {% trans "Any label, for example SignalWire Main." %}
  • {% trans "Provider" %} — {% trans "Select SignalWire (Beta)." %}
  • {% trans "Status" %} — {% trans "Set to Active. The default is Inactive, and an Inactive provider is not offered when users click Call Now." %}
  • {% trans "Default Caller ID" %} — {% trans "Paste the SignalWire phone number from Part 1 (for example +12029004429)." %}
  • {% trans "Account SID" %} — {% trans "Paste the Project ID." %}
  • {% trans "Auth Token / API Secret" %} — {% trans "Paste the API token you created." %}
  • {% trans "API Base URL" %} — {% trans "Paste the Space URL, for example your-space.signalwire.com. Adding https:// in front is optional." %}
  • {% trans "Webhook Secret" %} — {% trans "Required. Paste the Signing Key from your SignalWire project's API page. Status callbacks that are not signed with it are rejected." %}

{% trans "Click Save, then use the Test Connection action on the provider row. You should see Connection successful. HTTP 401 means the Project ID or API token is wrong or has extra spaces; a connection error or HTTP 404 usually means the Space URL is wrong." %}

{# ── Telnyx ── #}
{% trans "How to configure Telnyx (Beta)" %}
{# Before you start #}

{% trans "Before you start" %}

  • {% trans "You need a Telnyx account. Sign up free at" %} telnyx.com/sign-up {% trans "and sign in to the portal at" %} portal.telnyx.com.
  • {% trans "New accounts start at the Pretrial level (shown next to the Upgrade link at the top of the portal). Some features, such as Verified Numbers, are blocked at that level — see Part 2." %}
{# Part 1 #}

{% trans "Part 1 — Collect your details from Telnyx" %}

  1. {% trans "Create an API key" %} — {% trans "Click the profile icon at the top right and choose API keys. Click Create API Key and copy the key straight away — it is shown only once. It starts with KEY. This is the Auth Token / API Secret in the CRM form." %}
  2. {% trans "Create a Voice API application" %} — {% trans "In the left sidebar open Programmable Voice → Applications and click Add new application (choose the Voice API / Call Control type, not TeXML). Give it a name such as CRM Calls. If the form asks for a webhook URL, enter any valid https:// address; the CRM supplies its own webhook for every call." %}
  3. {% trans "Set up outbound calling on the application" %} — {% trans "In the application's settings find the Outbound tab (or Outbound Voice Profile) and select an Outbound Voice Profile. If none exists, create one under Outbound Voice in the sidebar and allow the countries you will call. Save the application." %}
  4. {% trans "Copy the Connection ID" %} — {% trans "Open the application again and copy its ID (a long value like 1234567890123456789). This is the Connection ID in the CRM form." %}
  5. {% trans "Buy a phone number" %} — {% trans "In the sidebar open Numbers → Phone Numbers and click Buy number. Pick a number with Voice enabled and complete the order. Phone Numbers only lists numbers you buy from Telnyx — your personal mobile number will not appear there." %}
  6. {% trans "Link the number to your application" %} — {% trans "In Numbers → Phone Numbers, open the number and set its Voice connection to the application you created." %}
  7. {% trans "Copy the number" %} — {% trans "Copy it in E.164 format: a plus sign, the country code, then the digits with no spaces, brackets or dashes (e.g. +12125551234). This is your Default Caller ID." %}
{# Part 2 #}

{% trans "Part 2 — Pretrial accounts: upgrade before you test" %}

{% trans "Open Numbers → Verified Numbers. If it shows “This feature is not permitted at this account level”, your account is still at the Pretrial level. Click Upgrade at the top of the portal and complete the steps Telnyx asks for (such as account verification or adding a payment method). After the upgrade:" %}

  1. {% trans "Open Numbers → Verified Numbers → Verify Number and add the mobile number you want to test with, including the country code." %}
  2. {% trans "Enter the verification code Telnyx sends or reads out." %}
  3. {% trans "Use this verified number as the phone number on the Lead or Contact you test with." %}
{# Part 3 #}

{% trans "Part 3 — Enter the details in this form" %}

{% trans "Click Add above and fill in the form:" %}

  • {% trans "Name" %} — {% trans "Any label, for example Telnyx Main." %}
  • {% trans "Provider" %} — {% trans "Select Telnyx (Beta)." %}
  • {% trans "Status" %} — {% trans "Set to Active. The default is Inactive, and an Inactive provider is not offered when users click Call Now." %}
  • {% trans "Default Caller ID" %} — {% trans "Paste the Telnyx phone number you bought in Part 1." %}
  • {% trans "Auth Token / API Secret" %} — {% trans "Paste the API key (starts with KEY)." %}
  • {% trans "Connection ID" %} — {% trans "Paste the application ID from Part 1." %}
  • {% trans "Webhook Secret" %} — {% trans "Required. Paste your Telnyx Public Key (profile icon → API keys → Public Key) — it is not a password you make up. Status callbacks that fail the signature check are rejected." %}

{% trans "Click Save, then use the Test Connection action on the provider row. You should see Connection successful. HTTP 401 means the API key is wrong or has extra spaces; HTTP 403 means your account level does not allow the request." %}

  4. {% trans "Copy the API Token" %} — {% trans "Copy the API Token (reveal it first if it is hidden). This is the Auth Token / API Secret in the CRM form. Treat it like a password." %}
  5. {% trans "Find your ExoPhone" %} — {% trans "In the dashboard open the ExoPhones page (under Numbers or Phone Numbers). Copy the number assigned to your account. This is your Default Caller ID." %}
{# Part 2 #}

{% trans "Part 2 — Trial accounts: the numbers you will call" %}

{% trans "A trial Exotel account can usually call only numbers that you have added or verified in the dashboard. Add the agent's phone and the test customer's phone there before you test." %}

  • {% trans "Account SID" %} — {% trans "Paste the Account SID." %}
  • {% trans "API Key" %} — {% trans "Paste the API Key." %}
  • {% trans "Auth Token / API Secret" %} — {% trans "Paste the API Token." %}
