What is Horilla CRM?

Horilla CRM is an open-source customer relationship management platform that brings sales, marketing, customer data, scheduling, analytics, automation and administration together in one system. This documentation covers the complete working cycle it supports, from capturing a lead through to managing deals and forecasting revenue.

Integrated Platform Foundation

Every module shares a single workspace, so records, people and activity stay connected rather than siloed. Real-time notifications are delivered over WebSockets, and background processing is handled by Celery.

Key Capabilities

Flexible Visualisation

Records can be viewed as a List, Kanban board, Card grid, Group By breakdown, Chart, Split view, Timeline or Oldest First. Group By can expand the groups in view and continue as the user scrolls, and those groups support the same bulk actions as the list. A detail page edits its fields through Edit Details, which checks the form the same way a normal save does and shows each mistake under its field.

Advanced Filtering and Customisation

  • Multi-condition filters that can be saved and reused.
  • Personalised column selection per list.
  • Recently Viewed, Recently Created and Recently Modified tracking.

Automation and Integration

  • Message automations.
  • Workflow rules.
  • Sales cadences.
  • WhatsApp accounts, templates, flows and bot rules. Incoming webhooks are accepted only when Meta's signature matches the account's app secret.
  • Google Calendar synchronisation.
  • Email to Record, which can create a Lead or a Contact from the Inbox.
  • Web-to-Lead forms.
  • Public booking pages.
  • A Product Tour of Home and Leads, plus tours for the other main record screens. A step is skipped when it is not on the page.

Robust Data Management

  • Bulk update, delete and export.
  • Export in multiple formats.
  • Import with field mapping.
  • Recycle Bin for deleted records.
  • Audit trails.
  • Duplicate detection and record merging.

Real-Time Collaboration

  • Live in-app notifications.
  • Dashboard metrics that update in real time.
  • Streaming activity feeds.

Access Control and Security

  • A four-layer permission model: model level, field level, row/owner level and role hierarchy. Users granted access to a record can act on it according to that grant.
  • A company chooses the languages it offers. A user's language list is limited to those languages.
  • Currency rates can refresh on a schedule, and each non-default currency can keep a dated history.
  • Company-based multi-tenancy.
  • User groups.
  • Opportunity team access granted as Read/Write or Read-Only.
  • Login history per user.

Tailored Adaptability

The platform suits both small sales teams and multi-branch enterprises, and because it is open source it can be extended to fit requirements that the standard configuration does not cover.
