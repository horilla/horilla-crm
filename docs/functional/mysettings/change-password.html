My Settings

Change Password

Replace the password for the signed-in user.

Change Password

Go to My Settings → Change Password. The page title is Password Management. The description is Update your password to keep your account secure.

The Password card shows Last Updated and a Change Password button. The button opens Change Your Password.

Change Your Password

The dialog title is Change Your Password. All three fields are required. Each field has a control to show or hide the password. Change Password at the bottom of the dialog stores the new password.

Field Description
Current Password The password in use. Placeholder: Enter Current Password.
New Password The replacement password. Placeholder: Enter New Password. It has to meet the site password rules and differ from the current password.
Confirm New Password The new password typed again. Placeholder: Confirm Your Password.

A wrong current password, a new password that fails the rules, or a confirmation that does not match stays on the form with the error next to the field.
