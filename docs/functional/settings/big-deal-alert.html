Settings

Big Deal Alert

Watch high-value opportunities, set alert thresholds and have the right people notified by mail or in-app notification as soon as the conditions are met.

Introduction

The Big Deal Alert module helps organisations monitor high-value opportunities, set alert thresholds, receive timely notifications and act quickly. Centralised visibility and deal insights help stakeholders make better decisions and improve sales performance.

Key Features and Functionalities

1.1 Big Deal Alerts Overview

Purpose: list the Big Deal Alerts for the company. The page description is Get notified automatically when a high-value opportunity is created.

  • Location: Settings → Opportunity → Big Deal Alerts.
  • Each alert is a row with its title, edit, delete and an expand control.
  • Clicking a title expands the row to reveal the full configuration.
  • Quick search and filtering help locate an alert.
  • Each row provides Edit and Delete actions.
  • When no alerts exist, an empty state prompts the user to create the first one.

1.2 Configuring Big Deal Alerts

Purpose: let users create and manage alerts for high-value opportunities.

  • Click New in the top navigation bar to open the creation form.
  • The form uses the automation framework and is linked automatically to the Opportunity module.

Form Fields

Field Description
Title Full-width text field holding the alert name. Required, and must be unique across the system.
Trigger Dropdown defining when the alert fires: On Create, On Update, On Create or Update, On Delete, Scheduled.
Delivery Channel Dropdown controlling delivery: Send as Mail, Send as Notification, Send as Mail and Notification.
Mail Template Dropdown selecting the email body. Shown when the delivery channel includes mail.
Outgoing Mail Server Dropdown selecting the sending mail server. Shown when the delivery channel includes mail.
Notification Template Dropdown selecting the in-app notification. Shown when the delivery channel includes notification.
Mail to / Notify to Text field for recipients. Accepts direct email addresses, the keyword self (the user who triggered the action), dynamic field references, and multiple comma-separated entries.
Also Send to Multi-select for extra users, who receive the notification as CC recipients.

Conditions

Conditions are dynamic rows, each defining when the alert fires based on Opportunity field values. Each row contains:

Element Description
Field The Opportunity field to evaluate, such as Amount or Probability.
Operator The comparison: equal, not equal, greater than, less than, greater than or equal, less than or equal, or contains.
Value The threshold to compare against.
Logical Operator AND or OR, used to chain conditions together.

Multiple conditions can be added for more precise control.

Scheduled Trigger Fields

These fields appear only when Trigger is set to Scheduled.

Field Description
Target Date Field The date or datetime Opportunity field the schedule is based on.
Adjust By Numeric offset.
Timing Whether to fire before or after the target date.
Offset Unit Days, weeks or months.
Run Time Optional time of day at which to fire.

1.3 Alert Expanded View

Purpose: show the full alert settings inline within the list.

Click the alert title to expand it. Big Deal Over 100k opens a two-column grid:

  • Trigger Amount — Greater Than 100000
  • Notify Emails — instance.owner.email
  • Trigger — On Create
  • Delivery Channel — Send as Notification

A mail alert also shows Mail Template and Sender Email. Notify CC Emails appears when extra recipients are selected.

1.4 Notifications and Delivery

Purpose: ensure timely, automated communication about high-value deals.

Active alerts monitor Opportunities continuously and send notifications automatically once their conditions are met.

Delivery Channels

  • Mail – sends an email using the selected mail template through the configured outgoing server.
  • Notification – sends an in-app notification using the selected notification template.
  • Both – sends the email and the in-app notification together.
  • Recipients are resolved when the alert fires, based on Mail to / Notify to.
  • Users listed in Also Send to receive CC copies.
  • Scheduled alerts fire from a date field on the Opportunity, with a configurable offset and an optional run time.

1.5 Edit and Delete Functionality

Purpose: keep alerts accurate and current.

Edit

  • Click the edit icon on an accordion row to open the update form in a modal.
  • Title, trigger, conditions, delivery channel, templates and recipients can all be changed.
  • Changes appear in the list immediately.

Delete

  • Click the delete icon on an accordion row to open a confirmation prompt before permanent removal.
  • The confirmation step guards against accidental deletion.
  • Once deleted, the alert is removed and all of its notification activity stops.
