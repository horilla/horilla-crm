Settings

Colour Theme

Change the appearance of the whole application by activating one of the pre-built colour themes.

Introduction

Administrators can change how the whole application looks by selecting from a set of pre-built colour themes. The active theme applies company-wide to navigation, buttons, icons, forms and background surfaces. An administrator can also set one theme as the default for the login page.

Key Features and Functionalities

1. Colour Theme Overview

Purpose: show every available theme in a grid so administrators can activate and manage them.

  • Menu path: Settings → Theme Manager → Color Theme.
  • The page title is Theme Management. The line under it reads: Select a theme to customize the appearance of your application.
  • Each card shows a colour strip, the theme name, a short description, and Set as Default. The theme in use for the company is marked (Active) with a check. The login default shows Default Theme instead of Set as Default.

2. Available Themes

The product ships these color themes. They appear as cards on this page once the theme records are installed:

  1. Coral Red Theme (Default)
  2. Ocean Blue Theme
  3. Forest Green Theme
  4. Purple Professional Theme
  5. Slate Gray Theme
  6. Indigo Night Theme
  7. Sunset Orange Theme
  8. Crimson Wine Theme – a deep crimson palette
  9. Teal Corporate Theme
  10. Amber Glow Theme
  11. Navy Steel Theme
  12. Rose Gold Theme
  13. Emerald Mint Theme

3. Activating a Theme

Purpose: apply a theme to the whole application, for every user in the company.

  1. On the Colour Theme page, browse the theme cards.
  2. Click Activate on the card you want.
  3. The page reloads and the new theme is applied across all pages, navigation and UI components.
  4. The chosen card then carries the (Active) label.
Note

Activation is company-wide. Other users in the same company see the change on their next page load.

4. Setting a Default Theme for the Login Page

Purpose: control which theme is shown on the login screen, before a user signs in.

  1. On the Colour Theme page, find the theme you want on the login page.
  2. Click Set as Default on that card.
  3. The theme is then applied to the login page for all visitors.
  • Only one theme can be the login default at a time; setting a new one removes the flag from the previous default.
  • To clear the default without choosing another, click Remove as Default on the current default theme.
  • The login theme is independent of the company's active application theme.
  • A user's last active theme is stored in their browser, so the login screen reflects the theme from their previous session until the global default overrides it.

Best Practices

  • After activating a theme, check the dashboard, Kanban, forms and calendar for readability and consistency.
  • Use Set as Default so the login page carries the organisation's brand colours.
  • Only one theme can be active at a time; activating a new one immediately replaces the old one for all users.
  • Coordinate theme changes with the team so the interface does not shift unexpectedly during business hours.
  • Coral Red Theme (Default) is the system baseline and is applied automatically when no company theme has been configured.
