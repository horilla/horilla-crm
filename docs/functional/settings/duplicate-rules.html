Settings

Duplicate Rules

Set what happens when a record matches a matching rule.

Duplicate Rules

Go to Settings → Duplicate Control → Duplicate Rules. The page title is Duplicate Rules. The description is Set how duplicate records are handled once matched.

Columns are Name, Module, Matching Rule, Action on Create, Action on Edit, Is Active and Actions. Actions are Edit and Delete. Click the name to open Details. The comparison itself is defined on Matching Rules.

Is Active is a switch. Only one rule can be active for a module. Turning a rule on turns off the other active rule for that module.

Create Duplicate Rule

Click New. The form title is Create Duplicate Rule. Save stores the rule. Save & New stores it and opens a blank form.

Field Description
Name Name of the rule. Placeholder: Enter Name.
Module Account, Contact or Lead. Placeholder: Select Module.
Description Optional notes. Placeholder: Enter Description here...
Matching Rule A matching rule for the selected module. Placeholder: Select Matching Rule.
Action on Create Allow or Block. The form opens on Allow.
Action on Edit Allow or Block. The form opens on Allow.
Alert Title Heading of the warning. Opens as Potential Duplicate Detected.
Customize Message Per Action No uses one Alert Message. Yes shows Alert Message (Create) and Alert Message (Edit).
Alert Message Body of the warning. Opens as Similar records found. Do you want to proceed?
Show Duplicate Records Lists the matching records in the warning.
Is Active Whether this rule is the active one for the module.
Conditions Optional filters. With none set, the rule applies to every record in the module.

Details

Click the rule name. The dialog title is Details, then the rule name. It lists Name, Description, Module, Matching Rule, Action on Create, Action on Edit, Show Duplicate Records, Alert Title and the alert messages. Edit and Delete are on the dialog.

Warning on create or edit

Saving a record checks the active duplicate rule for that module. A match opens a warning with the alert title, the alert message and, when Show Duplicate Records is on, the matching records.

  • Allow offers Continue, which saves the record, and Cancel, which returns to the form.
  • Block offers OK. The record is not saved.

Potential Duplicates

Lead, Contact and Account detail views include a Potential Duplicates tab. It lists records that match the current one, with a Merge action.

Warning

A merge can include at most 3 records, counting the current one.

Select the records, then click Merge.

  1. Compare. Fields are shown side by side. The radio button at the top of a column picks that record as the master and selects its values. A field can take its value from another column.
  2. Summary. The master record and the chosen value for each field are listed. Confirm continues.
  3. Merge. The master record is updated. Every record that was not the master is deleted.
Warning

Merging deletes every record that was not chosen as the master.
