Settings

Field Management

Add fields, choose which fields a create form shows, and decide which fields are required, per company.

Overview

Go to Settings → Field Management. The section has three pages: Custom Fields, Form Layout and Field Requirements. Each setting belongs to the active company. Today these pages apply to Leads and Opportunities.

Custom Fields

A custom field captures extra information on Leads and Opportunities. The page description is Define custom fields to capture additional information on Leads and Opportunities. Saved fields list Name, Model, Type, Required, Order and Actions. New opens the create form.

Once saved, the field is available wherever that model's data is shown, subject to field permissions:

  • Create and edit forms, including the wizard.
  • The detail header, the Details tab, inline edit and Edit Details.
  • List columns, the column picker, filters and quick filters.
  • Kanban, Group By and Chart, for a single-choice field.
  • Import templates, export, scheduled export, reports and dashboard components.
  • Condition builders used by approvals, reviews, workflow, automations, cadences, duplicates, scoring and forecast.
  • The Insert Fields list on mail and notification templates.

A hidden field permission removes the field from those surfaces. A read-only permission shows it but does not accept a change. An applied filter chip shows the field's name.

Form Layout

The page description is Choose which fields appear and in what order. Available as a Custom Layout mode on create and edit forms. Each saved layout is one row, with Model, Fields Shown, Last Updated and Actions. Fields Shown is the number of visible fields out of the fields on that form.

Field Requirements

The page description is Choose which fields your team must fill in when creating or editing records. Each row lists Model, Field, Requirement (Required or Optional) and Actions.

Expected Behaviour

  • A field added for one company does not appear for another company.
  • Deleting a custom field removes it from forms, lists, filters, exports and conditions.
  • A user without view permission on the page does not see that Field Management item.
