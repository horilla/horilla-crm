Settings

Inbox and Outbox

Read mail the CRM has fetched, and review mail it has sent.

Overview

Both lists live under Settings → Mail, next to the outgoing server, the incoming server and mail templates.

Inbox

Go to Settings → Mail → Inbox. The description is Review emails fetched from your incoming mailboxes. With no fetched mail, the page shows Nothing to show yet. Please add your Incoming Mails.

Email to Record uses this inbox. A matching message can create a Lead or a Contact.

Outbox

Go to Settings → Mail → Outbox. The description is Review the emails sent from the system. Columns are Send To, Subject, Mail Status, From, Sent By and Sent At, with Actions. A checkbox and Select sit above the rows. Select shows the number of rows.

A draft row offers Send Email and Delete. Sent By and Sent At stay blank until the mail is sent.
